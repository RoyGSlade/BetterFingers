Alpha 4 is a prerelease of BetterFingers, a private, local-first desktop dictation app:
speak, review the draft, and place clean text into the app you are working in. It ships
as a signed Windows 11 x64 installer and an experimental Linux AppImage. It is alpha
software; do not use it for highly sensitive dictation (there is no at-rest encryption).

## What's new

- **Dictation works offline right after install.** The `base.en` speech model now ships
  inside the installer, checked against pinned SHA-256 hashes, so your first dictation
  needs no download. BetterFingers never downloads a speech model on its own: larger
  models download only when you click Download. If the model is missing or damaged, the
  app still opens and tells you so in Models instead of waiting on the splash screen. On
  one laptop (Ryzen AI 9 HX 370, CPU) the bundled model loaded in 0.58 s and transcribed
  a 10.7 s clip in 0.61 s, with the network blocked and no connection attempts (measured
  from a bundled copy, not yet from a signed installer).
- **F9 accepts and places the draft you are looking at.** In review mode, one press of
  the Primary Action key (F9 by default) accepts and places the draft the review overlay
  is showing, so there is no separate Accept step. It only acts on the exact draft on
  screen: if you have unsaved edits, or the draft changed after it was shown, F9 refuses
  rather than guess, and a double press cannot place the same draft twice. With no
  overlay open, F9 still reads your selected text aloud. In games, text is still copied
  to the clipboard, never typed.
- **Update checks are consent-first.** Nothing contacts the update server until you have
  accepted the privacy notice, and on a fresh install automatic checks stay off until you
  tick **Check automatically** on the Settings update card. **Check for updates** works
  by hand after consent. The card says where it connects and why.
- **Report a bug from inside the app** (Utilities, Diagnostics, **Report a Bug**). You see
  exactly what would be shared, a short list of coarse diagnostics plus what you typed,
  never transcripts, audio, file paths or raw logs, and you confirm it. No server
  receives reports yet, so the app copies the report and opens your email client or the
  Discord invite. It never says a report was sent unless something confirmed it.
- **Deleting something now deletes the backup copies too.** Removing one item (a draft or
  history entry, a persona or persona example, a contact, a dictionary or macro entry, a
  voice preset) now also removes it from the backup and snapshot copies BetterFingers
  keeps for recovery, and the history database no longer keeps deleted dictation text in
  freed space. Wipes cover those backup and quarantine copies, and the Windows
  uninstaller's **remove my data** option now deletes them as well (Alpha 3 left them
  behind).
- **Spoken edit commands understand "don't".** "Don't scratch that" no longer scratches
  your last sentence, and "do not delete last word" no longer eats a word. Harmless
  phrasing such as "send it, no problem" still works. Only commands are affected; your
  dictated words are never altered by this rule.
- **Faster dictation on the CPU.** Whisper now chooses its CPU thread count from your
  machine instead of a fixed default. On one laptop (Ryzen AI 9 HX 370, 10.7 s of speech,
  int8) transcription took 1.10 s instead of 1.42 s with `base.en` and 1.81 s instead of
  2.34 s with `small.en`. On a machine with an NVIDIA GPU but no CUDA libraries (the
  installed app does not ship them), the fall-back to the CPU now happens while the model
  loads rather than during your first dictation: on the same laptop (RTX 5070, no CUDA
  libraries) first `small.en` dictation took 1.62 s instead of 2.11 s, at the cost of a
  longer model load (1.42 s instead of 0.60 s). These are single-machine measurements;
  yours will differ.

### Fixed

- **Safer around games and chat keys.** Dictating right after you switch into a game now
  checks the window that will actually receive the text, not the last window the
  dashboard happened to notice. The "open chat, then send" action can no longer type
  into a game while the gaming protection is on. Profiles built by the Game Mode wizard
  now switch that protection on, and the wizard no longer asks for a chat key it could
  not save.
- **Clipboard save and restore can no longer crash the app.** If your clipboard holds
  something BetterFingers cannot safely copy (for example a very large or unusual
  format), reading a selection now stops cleanly instead of risking a crash or losing
  what you had copied.
- **Status screens stay responsive while the speech model loads.** Status, health and the
  support report no longer wait for a model load to finish.
- **Dictating without a speech model says so.** You now get "speech model is missing"
  instead of "No usable audio was recorded", and the first-run checklist counts the
  speech model you selected, not just any model.
- **Transcription can no longer freeze after a failed GPU attempt.** Once a GPU attempt
  fails in a session, BetterFingers does not try it again, so reloading a model (for
  example switching Whisper size) cannot hang.
- **A bad delete can no longer wipe a whole collection.** Clear-all requests for
  recordings, history, drafts, persona examples and message-rescue context now need an
  explicit confirmation, so a malformed single-item delete cannot empty them.
- **Read-aloud voice files are verified before use.** The first read-aloud downloads the
  Kokoro voice model and voices (about 325 MB and 28 MB). Each download is now checked
  against a pinned size and SHA-256 and discarded if it does not match, and a truncated
  file left behind by an interrupted download is fetched again instead of being loaded.
- **Settings and status polish.** Five Settings controls that did nothing were removed
  (draft history limit, Whisper chunk size, and the status-indicator, notification-overlay
  and preview-overlay on/off switches); your saved values are kept. Saving settings now
  refreshes the dependent panels in the right order, and one failing panel no longer stops
  the rest. The status bar's details button opens Runtime Diagnostics, navigation
  announces the current page to screen readers, muted text has higher contrast, and
  **Clear history** reports a failure instead of pretending it worked.
- **Local AI runtime install on Windows.** Installing the local language-model runtime no
  longer fails on Windows machines that do not allow symbolic links.

## Under the hood

- The installer build bundles the pinned Systran `base.en` speech model, checked against
  SHA-256 hashes at build time and again at load, together with its MIT notices
  (`licenses/bundled-base.en-NOTICE.txt`). The frozen backend grows by 147,769,510 bytes
  for it (425.04 MB to 572.81 MB, measured on a backend build, not on a signed
  installer; an installer total has not been measured). A build must now say where the
  model comes from; see `docs/DEVELOPMENT.md`, Building.
- Every automatic speech-model load (warmup, residency preload, recording, re-transcribe,
  streaming, the recommender, Doctor and status) is local-only; only the explicit Download
  route can fetch. The loader prefers a verified bundled `base.en` even when downloads are
  allowed. A bundle that fails verification reports `verification_failed` and is never
  repaired from the network, the model list counts a verified bundle as installed, and
  removing it is refused. Other model sizes, and development runs without a bundle, use the
  local Hub cache only.
- A content-free latency recorder times each dictation from the stop key to the finished
  draft, stage by stage, and exposes counts and percentiles locally under `/metrics`. It
  records no text, paths or identifiers, makes no network calls, and cannot change what
  dictation does. Its overhead was measured with fakes only (about 41 microseconds per
  dictation), not with real models.
- Transcriber and speech-engine status are published as immutable snapshots, so readers
  never wait on the model lock.
- Windows release signing now goes through Azure Artifact Signing with environment-scoped
  OIDC, and every tag build must be signed. Native `.pyd` and `.node` modules are signed
  along with the `.dll` files, non-x64 input-hook prebuilds are left out of the Windows
  package, and the update metadata pins the publisher name (CN, O, C). Contract tests pass;
  no signed build had been run when these notes were written.
- Developer-only: when NVIDIA cuBLAS/cuDNN are installed in the dev environment,
  Whisper runs on the GPU. On one RTX 5070 laptop `small.en` took 0.42 s for a first
  dictation (1.62 s on the CPU). The installed app does not include this.
- The backend moved from the repository root into `backend/` packages, with a thin
  `server.py` and one router per domain. No behavior change was intended; guardrail tests
  pin the layout, the route table and the import rules.
- Design documents landed for modes, a two-screen first run, automatic model selection,
  assistant actions, per-stage latency and a settings consolidation. They are plans only.
- `LICENSES-MODELS.md` now inventories every model and runtime the app ships or downloads.
- Wake-word setup plumbing (phrase-quality check, setup registry) and tests were added
  behind the wake-word settings, which stay hidden in this release.
- The parity ledger reads 404 wired, 34 intentional cuts, 0 blocked (438 items). That
  shows source and test anchoring, not user-level qualification.

## Known limitations

- **Only `base.en` is bundled.** Every other speech model still needs a network download
  that you start yourself, and a damaged bundled copy is reported rather than silently
  re-downloaded.
- **Single-machine evidence.** Every speed figure above comes from one laptop. There has
  been no clean Windows 11 matrix, no microphone or game compatibility sweep, and no
  SmartScreen reputation check. Windows may still warn about a new, low-download
  installer; verify the signature and the SHA-256 sidecar before you run it.
- **F9 has not been tried against real target applications.** Its behavior is covered by
  automated tests; placing text into your own apps is what Alpha 4 testers are for.
- **Speech-to-text runs on the CPU in the installed app.** GPU transcription is
  developer-only for now (no CUDA libraries are shipped, and AMD/Intel GPU support is not
  offered).
- **The first read-aloud downloads about 354 MB without asking.** The Kokoro voice files
  are not in the installer; the download starts on first use, with no separate prompt in
  this release. An explicit download step comes with the optional voice pack, after
  Alpha 4. The SHA-256 pins are trust-on-first-use (the upstream release publishes no
  digests), and the smaller fp16/int8 variants are size-checked only.
- **No bug-report server exists yet.** In-app reports are a copy-and-open handoff to your
  email client or Discord, not an automatic submission.
- **Negation rules are conservative, not perfect.** "No, send it" (with a comma) still
  sends, "do not, under any circumstances, delete last word" still deletes, and spoken
  formatting commands do not understand negation. The rule relies on Whisper's punctuation.
- **Deleting a persona or voice preset is refused while its live file is unreadable.** The
  next normal load quarantines the bad file, after which the delete works.
- Voice cloning, wake-word settings and workflow settings stay hidden. At-rest encryption
  is not included, and raw recordings are kept for recovery until you delete or wipe them.
- Linux is experimental (X11 is the stronger path; Wayland is best effort). macOS is not
  supported.

## Upgrading from Alpha 3

- **How:** run the Alpha 4 installer over your Alpha 3 install. If your Alpha 3 update
  card finds Alpha 4 in Settings, **Download update** and **Restart and install** are
  separate steps, and the update is only accepted if it is signed by the same publisher
  identity Alpha 3 expects. If that check fails, install over the existing copy by hand.
  Your settings, models, recordings and history are kept either way. The Alpha 3 to
  Alpha 4 in-app update is the first real test of that path and had not been exercised
  when these notes were written.
- **Update checks:** an Alpha 3 install that was already checking automatically keeps
  doing so; the new **Check automatically** box on the update card controls it, and
  turning it off is honored. An install with no recorded consent, or an unreadable
  record, stays off until you accept the privacy notice. One caveat: if you later
  reinstall an older build, it can drop the stored preference, and the newer build will
  then read an opted-out profile as opted in.
- **Speech models:** BetterFingers no longer downloads a speech-to-text model by itself,
  including on first dictation. If the model you selected is not installed you get a
  "Download it in Models" message instead of an automatic download; `base.en` comes from the
  installer and needs nothing.
- **Settings:** the five removed controls are gone from the UI, but their saved values stay
  in your profile and exports; nothing was reset.
- **F9:** it now accepts and places the draft the review overlay is showing. If you used
  it to send a draft you could not see, open the review overlay first.
- **Old backups:** the new delete behavior applies from the moment you delete something.
  Items you deleted in Alpha 3 or earlier may still sit in old backup copies; a wipe, or
  the uninstaller's **remove my data**, clears them. (Inferred from how the fix works;
  not tested against an Alpha 3 profile.)

## Not in this release

- The optional Natural Voices / text-to-speech pack. The Kokoro runtime stays bundled, as
  in Alpha 3; its voice files still download on first read-aloud (see Known limitations).
- Modes (Work, Gamer, Ideas and so on).
- The first-run microphone level meter.
- GPU acceleration for installed builds. CUDA is developer-only; AMD and Intel (Vulkan)
  options are still being evaluated.
