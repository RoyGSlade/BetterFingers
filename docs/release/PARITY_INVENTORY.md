## Release-status rule

`wired` requires the full Wave 11 chain: reachable production Signal Desk location, real data source, real action handler when actionable, user-visible failure state, keyboard/accessibility evidence, QA coverage, and privacy review. The legacy catalog and the five preview placement maps are useful discovery evidence, but their boolean `wired: true` values do not satisfy that release definition: Signal Desk is still an opt-in QA preview, several workspaces are fixture-seeded, and per-item failure/accessibility/QA/privacy evidence is not complete. Accordingly this Gate 0 ledger does not promote any row to `wired` merely because a legacy handler or preview control exists.

`intentional_cut` is used only for the four checklist entries that describe the static, fixture-only Message Rescue example surface. The directive forbids production mock data and removes preview pages as production targets. No checklist row describes the proposed Library waveform thumbnail, so the directive’s separate waveform cut creates no fifth ledger row.

## Reproducible validation

Each row's `Source binding` is
`sha256("<stable-id>\n<source-ref>\n<normalized-full-checkbox-text>")`. The following read-only
check verifies the stored source-file SHA-256; parses every checkbox, including its indented
continuation lines; reconstructs the exact section, within-section ordinal, and source line;
and recomputes every row-level binding. It also verifies ordered unique IDs, status vocabulary
and totals, and the displayed source-section and workspace summaries.

from collections import Counter, defaultdict
from pathlib import Path
import hashlib
import re

source_path = Path('docs/ui/CURRENT_UI_INVENTORY.md')
ledger_path = Path('docs/release/PARITY_INVENTORY.md')
source_bytes = source_path.read_bytes()
source = source_bytes.decode('utf-8').splitlines()
ledger = ledger_path.read_text(encoding='utf-8').splitlines()

stored_source_sha = re.fullmatch(
    r'- \*\*Source SHA-256 at audit:\*\* `([0-9a-f]{64})`\.',
    next(line for line in ledger if line.startswith('- **Source SHA-256 at audit:**')),
).group(1)
actual_source_sha = hashlib.sha256(source_bytes).hexdigest()
assert stored_source_sha == actual_source_sha, (stored_source_sha, actual_source_sha)

section = None
section_titles = {}
ordinal = {}
expected = []
for index, line in enumerate(source):
    heading = re.match(r'^## (\d+)\.\s+(.*)$', line)
    if heading:
        section = int(heading.group(1))
        section_titles[section] = heading.group(2)

    marker = re.match(r'^(\s*)- \[[ xX]\] (.*)$', line)
    if not marker:
        continue
    assert section is not None
    ordinal[section] = ordinal.get(section, 0) + 1
    stable_id = f'UI-{section:02d}-{ordinal[section]:03d}'
    source_ref = f'§{section} item {ordinal[section]:03d} · L{index + 1}'

    parts = [marker.group(2).strip()]
    continuation_index = index + 1
    while continuation_index < len(source):
        continuation = source[continuation_index]
        if not continuation.strip():
            break
        if (
            re.match(r'^\s*- \[[ xX]\] ', continuation)
            or re.match(r'^#{1,6}\s', continuation)
        ):
            break
        indent = len(continuation) - len(continuation.lstrip())
        if indent <= len(marker.group(1)):
            break
        parts.append(continuation.strip())
        continuation_index += 1

    normalized_text = re.sub(r'\s+', ' ', ' '.join(parts)).strip()
    binding_payload = f'{stable_id}\n{source_ref}\n{normalized_text}'
    binding = hashlib.sha256(binding_payload.encode('utf-8')).hexdigest()

        'id': stable_id,
        'section': section,
        'source_ref': source_ref,
        'normalized_text': normalized_text,

        'id': stable_id,
        'workspace': workspace,
        'source_ref': source_ref,
        'concise': concise,
        'evidence': evidence,
        'binding': binding,
        'status': status_match.group(1),
