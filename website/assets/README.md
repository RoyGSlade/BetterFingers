# Project assets

No images or videos are currently supplied for the BetterFingers project
source. The manifest therefore keeps `screenshots` empty and omits the optional
`showcase`; the project page still carries its truthful `Product in
development` label.

When the final UI is ready for review, put project-owned showcase files under
`website/assets/showcase/` and reference them from `website/project.json`.
The central `docs/project-sources/SHOWCASES.md` guide supports one to three
images or videos per scene, gallery/workflow/cinematic treatments, captions,
video posters, containment choices, and multi-slide carousel controls. Do not
add placeholder or unreviewed UI media just to fill the carousel.
